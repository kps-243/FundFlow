FundFlow is a financial management application designed to help track and organize fund flows, budgets, and transactions.

## Features

- **Transaction Tracking** - Record and categorize financial transactions
- **Budget Management** - Set and monitor spending budgets
- **Reports** - Generate financial reports and analytics
- **Multi-currency Support** - Handle multiple currencies

## Installation

```bash
git clone https://github.com/kps-243/fundflow.git
cd fundflow
npm install
```

## Usage

```bash
npm start
```
